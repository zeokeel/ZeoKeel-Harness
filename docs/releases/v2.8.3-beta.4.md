## 一、左下角只保留一个「更多」

- **现象**：客户端底部出现两个「更多」：产品自己的面板入口一个，官方账户菜单一个。
  后者的菜单里只有「设置」，却常驻占一行，和产品入口重复。
- **修复**：隐藏官方账户菜单的触发按钮；把「设置」作为最后一项并入产品「更多」浮层。
  设置仍由官方 `settings.launcher` 打开，只是不再单独占一行。
- **验证**：E2E 断言可见「更多」按钮数量为 1，浮层包含「自动化任务 / 能力中心 / 连接器 /
  浏览器 / 应用中心 / 设置」，并且设置窗口仍可打开、账号页仍可达。

## 二、「更多」浮层改为不透明实底

- **现象**：在 Windows Mica / macOS vibrancy 等原生材质窗口上，浮层使用半透明层，
  下面的会话列表会透上来，看起来像一层透明膜。
- **修复**：浮层背景从半透明 `bg-layer-1` 改为实底 `bg-base`，保留边框与阴影。
- **验证**：E2E 读取浮层计算样式，背景 alpha 必须为 1；新增不透明背景判据。

## 已知限制

- 本版只修界面问题，beta.3 的能力与限制不变：旧 cron 任务不迁移；思考过程翻译默认走
  Bing，涉及敏感内容时不要展开思考过程。
- 半透明修复使用实底而非毛玻璃；在原生材质窗口上不再透视，但也不会呈现背景模糊。

## 升级与回滚

- 服务端：取本版镜像附件，按 `docs/deploy/AI-DEPLOY.md` 升级；升级前必须备份。
- 客户端：随服务端镜像分发，员工从自己登录的服务器取包。
- **回滚**：本版无数据库迁移，保留上一版镜像 tag 切回即可；客户端重装 beta.3 包。

- **迁移清单（机器可读锚点，供 `scripts/check-release-notes-migrations.mjs` 与 `git diff` 对拍）**：无
