# v2.11.5（2026-11-27）

> 一句话：调整连接器出站地址策略，DNS 解析到非公网地址时不再由客户端地址类别检查拦截；字面私网 IP、云 metadata、非 HTTPS 与解析失败仍会被拒绝。本版仅改桌面客户端连接器逻辑，服务端与数据库无需变更。

| 项目 | 说明 |
| --- | --- |
| 版本类型 | **正式版** |
| 升级建议 | 仅建议受控内网部署升级；需要连接内网 MCP 服务的客户端应升级 |
| 影响面 | 桌面客户端连接器 |
| 产品代码变化 | **有**（连接器出站策略） |
| 数据库迁移 | **无** |

## 一、连接器出站策略调整

- **现象**：某些 MCP 服务只在内部 DNS 下解析到内网地址；客户端连接器在 OAuth 注册端点或 MCP 端点校验阶段直接拒绝，导致连接器无法连接。
- **变化**：客户端不再按 DNS 解析结果的内网/链路本地/回环地址类别拒绝请求；解析结果仍会 pin 到实际连接，避免二次解析。
- **仍然保留**：仅允许 HTTPS（HTTP 仅 loopback）；拒绝 URL 中的凭据、字面私网 IP、云 metadata 主机名；DNS 解析失败、超时、空答案和不可读答案仍按原策略拒绝。
- **影响**：这是客户端连接器层面的策略变化，不改变服务端 MCP、RBAC 或数据库行为。

## 二、安全边界与部署建议

- 本版放开了“域名解析到私网”的地址类别拦截，**所有连接器**都受影响；不是只对某一个 MCP 服务放行。
- 建议只在受控内网部署升级，并在服务端网络/防火墙侧限制连接器可达的目标范围。
- 如果不需要连接内网 MCP 服务，可以继续使用 v2.11.4；升级前请评估该策略变化。

## 三、验证

- `yarn workspace @zeokeel/dsh-connectors test`：73 个测试文件、595 项通过；
- `yarn workspace @zeokeel/dsh-connectors build`：通过；
- 新增回归覆盖受控内网域名解析到私网地址时放行并 pin；
- 字面私网 IP、metadata 主机名、失败解析的既有回归继续通过。

## 四、升级与回滚

- **客户端**：升级到本版后重新连接连接器；
- **服务端/数据库**：本版无服务端代码与数据库迁移，可继续使用现有服务端镜像；
- **回滚**：回退到 v2.11.4 客户端；服务端无需回滚。
