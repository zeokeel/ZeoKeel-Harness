## 一、全新品牌标识

- **变化**：整仓切换到 ZeoKeel 新 logo —— 白色圆角底（日间）与黑色圆角底（夜间）配同一枚彩色图形；应用图标、官网、管理后台、登录页、侧边栏、OG 分享图与产品截图全部同步。
- **macOS 菜单栏**：仍只使用单色 template 图标（黑色 + alpha，系统按菜单栏明暗自动反白），并且改为**构建期**从当前渠道的完整图形派生，后续渠道自动继承自己的标识。
- **其他平台**：Windows / Linux 托盘与所有产品界面保持彩色标识，不使用单色版本。
- **验证**：品牌几何与桌面/企业/门户/站点四侧对拍；打包产物与官网构建均通过品牌守卫。

## 二、升级后不再每次启动都被登出

- **现象**：安装包升级到新版本后，已登录用户每次启动都被踢回登录页。
- **根因**：网关客户端包把 npm 的 `electron` 桩内联进产物，打包后的 main 进程拿不到 `safeStorage`，盘上已保存的会话读不出来。
- **修复**：构建期强制 `electron` external，并新增产物守卫；`safeStorage` 不可用时仍可恢复 0600 明文会话；恢复流程增加竞态保护，显式登录/登出不会被迟到的恢复覆盖。
- **验证**：新增会话恢复与竞态用例；打包产物构建守卫在 CI 构建期执行。

## 三、菜单不再出现「透明膜」

- **现象**：在 macOS vibrancy / Windows Mica 等原生材质窗口上打开侧栏菜单，卡片会透出下面的会话列表。
- **修复**：按桌面端的模式标记打开上游菜单的实底背板；菜单本身仍是半透明 + 模糊材质，只补上可模糊的底。
- **验证**：新增菜单背板回归用例与合成探针，覆盖浅色/深色两套主题。

## 四、技能管理不再白屏

- **现象**：打开 memory-evolve 的技能管理页面时白屏。
- **根因**：DSH 0.2.1 移除了带尺寸后缀的 `Icon*16/14` 导出，旧名字在运行时是 `undefined`。
- **修复**：全部改用 `Icon*Regular` 导出，并新增图标导出回归测试。

## 五、设置入口恢复响应

- **现象**：点击「更多」里的「设置」偶尔没有反应。
- **修复**：优先直接调用上游 launcher 的 `openSettings`，保留原有 DOM 菜单桥接作为回退。

## 已知限制

- macOS 菜单栏模板使用完整图形，16px 下细节较密；后续如有需要可单独出一版简化剪影。
- 预发布版不进入正式更新通道，正式客户端不会自动收到本版。

## 升级与回滚

- 服务端：取本版镜像附件，按 `docs/deploy/AI-DEPLOY.md` 升级；升级前必须备份。
- 客户端：随服务端镜像分发，员工从自己登录的服务器取包。
- **回滚**：本版无数据库迁移，保留上一版镜像 tag 切回即可；客户端重装上一版包。

- **迁移清单（机器可读锚点，供 `scripts/check-release-notes-migrations.mjs` 与 `git diff` 对拍）**：无

- `SHA256SUMS`：`sha256sum -c SHA256SUMS` 校验后再解压；
