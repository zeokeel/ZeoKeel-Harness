# v2.10.0-beta.1（2026-10-26）

> 一句话：能力中心完成现代化重构，并关闭发布/删除/审核链路上的 P0/P1 安全问题；管理端恢复中文展示名与权限门。预发布版本，不进入正式更新通道。

## 一、能力中心客户端重构

- **信息架构**：`全部 / 已安装 / 我上传 / 市场` 四分段（带计数），类型筛选、搜索、排序、网格/列表切换与结果计数收进统一工具条。
- **卡片与详情**：展示名作主标题、目录名作副标题；最多两个徽章 + 状态点；两行描述、单一主动作 + 「详情」；详情改为面板内整页子视图，版本列表/说明/操作集中展示。
- **状态**：加载态改为 6 张骨架卡；空态提供主操作；内置技能以普通卡片进入网格并计入分段角标与结果计数。
- **可访问性/主题**：仅复用共享面板组件与 `--dsw-*` 主题 token；保留键盘焦点、`prefers-reduced-motion` 与暗色主题。
- **客户端功能**：新增 `source=own` 提交面（pending/rejected/拒因可见）；卸载后立即移除并刷新；官方内容可更新；409 只在 `LOCAL_CONTENT` 时进入覆盖确认；上传前显示将发布版本并本地化版本类错误；安装/卸载/上传后刷新三个分区。

## 二、发布/删除/审核不变量

- **已通过版本不可删除**：`DELETE /shared-skills|agent-presets/:name/:version` 与 name 级删除都会返回 `409 RELEASE_APPROVED_NOT_DELETABLE`，归档与投影保持不变；停止分发请用可逆的「下架」。
- **空壳释放**：新增 `DELETE /api/server/admin/apps/:kind/:app_id`，只允许无版本、非官方的空壳；有版本/官方归属分别返回 409 指路，审计 `app_delete`。
- **规范化走统一发布内核**：`normalize` 落库改走 `appstore.Publish(AdminPublish=true)`，下架冻结、版本递增、changelog、官方/能力锁全部由内核原子判定。
- **展示版本唯一口径**：投影与交付统一取 semver 最大的 approved 版本（`PickCurrentRelease`），修复乱序批准导致的目录/下载分叉。
- **权限同权**：管理员直发/规范化与审批统一要求 `capability:write`，消除「能直发、不能审批」的反转。
- **审核原子性**：下架冻结写进同一条 UPDATE（`AND apps.enabled = 1`）；组织/市场/智能体三面审核统一走 `ReviewPending`；归属转移与发布共用 advisory 锁。

## 三、管理端

- **展示名**：`skillJSON`/`agentJSON` 下发 `display_name`（`apps.title → 展示版本 title → name` 回退），技能/智能体/审批三页用中文名作主标题、目录名作副标题；技能与智能体编辑支持「展示名」字段。
- **显示细节**：统一版本空态为「尚未发布」、下载/调用千分位、审批时间标注服务器本地时间；修复审批预览 key 的版本段丢失、作者/归属列头解释、内置来源与锁名说明。
- **权限与术语**：能力中心四页按权限渲染写按钮；状态与来源用词与客户端对齐；移除恒 false 的「名称冲突」徽章与残留「Git 源」文案。

## 四、数据库迁移

本版引入 5 条迁移（0086–0090）：

- **0086**：WASM 应用部署历史表 `wasm_app_deployments` + apps 部署指针/退役快照/清理时间线，`app_releases.status` 补 `withdrawn`。
- **0087**：WASM 应用级限流覆盖表 `wasm_app_limits`（四个并发轴，NULL=继承全局）。
- **0088**：`apps.data_cleaned_at` 真删两阶段化 + 部分索引 `idx_apps_purge_cleanup`。
- **0089**：`wasm_call_events.version` + (app_id,version,created_at) 索引，诊断按实际执行版本聚合。
- **0090**：`app_grants(grantee_type, lower(grantee))` 表达式索引（能力中心目录/下载热路径）；`app_releases.quality` 增加 `CHECK ('' | 'official' | 'featured') NOT VALID`（存量不回溯，新写入立即受约束）。

**部署注意**：0090 的索引创建不是 `CONCURRENTLY`，大表请在低峰窗口升级；旧版二进制与该组加法迁移兼容。

## 五、已知限制

- 市场「按版本下载/版本历史」「市场审批历史面」「市场精选」「审批队列分页/批量」为产品待定项，本版未实现；现有 UI 不渲染假入口。
- `author` 在组织/市场渠道仍分别表示上传者/负责人（管理端已用「作者（上传者）/归属（负责人）」两列区分）。
- 预发布版不进入正式更新通道，正式客户端不会自动收到本版。

## 六、升级与回滚

- 服务端：取本版镜像附件，按 `docs/deploy/AI-DEPLOY.md` 升级；升级前必须备份数据库。
- 客户端：随服务端镜像分发，员工从自己登录的服务器取包。
- 回滚：0086–0090 均为加法迁移，旧版二进制可继续运行；切回旧镜像前请确认数据库已备份，确需删除约束/索引时按对应迁移文件注释手工处理。

- **迁移清单（机器可读锚点，供 `scripts/check-release-notes-migrations.mjs` 与 `git diff` 对拍）**：`0086_wasm_app_deployments.sql`、`0087_wasm_app_limits.sql`、`0088_apps_data_cleaned_at.sql`、`0089_wasm_call_events_version.sql`、`0090_app_grants_grantee_index_and_quality_check.sql`
