## 一、本版变化：后台可配置百炼原生搜索

### 1. 后台配置

新增设置：

```text
web.search_provider = auto | bailian | off
```

- `auto`（默认）：非百炼上游保持原有行为；识别到百炼上游时补齐原生搜索标识；
- `bailian`：显式按百炼原生搜索处理，适用于自定义反代；
- `off`：客户端搜索 provider 不可用。

webadmin「网关」页的搜索区域新增“搜索提供方”选择；GET/PUT 接口返回/接受 `search_provider`，非法值 400 且不写库。

### 2. 百炼原生搜索标识

百炼 Anthropic 兼容 `web_search` 要求在请求的 `system` 中包含：

```text
x-anthropic-billing-header: cc_entrypoint=cli;
```

网关仅在 `bailian` 模式，或 `auto` 且上游是百炼托管域名、请求带 `web_search` 工具时追加该文本；普通聊天、非百炼上游、`off` 模式不修改请求体。不改变鉴权、上游 key、计费或搜索次数统计。

### 3. 客户端下发

bootstrap 的 `web` 增加 `search_provider`：

- `off`：清空客户端搜索 baseURL，provider 不可用；
- `auto` / `bailian`：继续使用 `${serverURL}/v1` 和网关 token，不向客户端下发上游 key；
- 旧服务端没有该字段时按 `auto` 兼容。

### 4. 边界

- `off` 是客户端能力开关，不拒绝第三方客户端直接发送 `web_search`；
- 配置在下一次登录/会话恢复时生效，已在线客户端不会实时刷新；
- 百炼模型需支持 `web_search`；不支持时按上游错误返回，不静默降级。

## 已知限制（本版认账，未修）

- **真实上游未验收**：beta 阶段仍需在百炼上游确认 billing 标识有效、搜索来源返回；当前以 fake upstream 与单元测试自证。
- **关闭不是服务端强制**：`off` 只关闭客户端 provider，不拒绝第三方客户端直接发送 `web_search`；网关仍按响应计费。
- **配置生效时点**：后台修改在下一次登录/会话恢复时下发，已在线客户端不会实时刷新。
- **百炼模型能力依赖**：模型不支持 `web_search` 时按上游错误返回，不静默降级。

## 三、升级与回滚

1. 服务端升级本版镜像；
2. 桌面客户端随镜像/安装包升级；
3. 如需百炼原生搜索，在 webadmin「网关」选择“百炼原生”；
4. 保持“自动”可避免改变非百炼上游的既有行为。

升级步骤见 `docs/deploy/AI-DEPLOY.md`；升级前必须备份，不要使用 `latest`，不要 `down -v`。

**回滚**：后台把 `web.search_provider` 改为 `auto`，或回退服务端镜像；无数据库迁移。
