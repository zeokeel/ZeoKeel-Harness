# v2.11.0-beta.1

> 一句话：这一版把企业微信 / 钉钉扫码登录做成完整的客户端登录方式，并接入 RBAC 外部身份源；登录页改为「点登录 → 浏览器扫码 → 客户端自动进入」，账号区显示员工真实姓名和登录来源图标。RBAC 解析默认关闭，不配置时不影响现有客户。

| 项目 | 说明 |
| --- | --- |
| 版本类型 | **预发布（beta）** |
| 升级建议 | 建议测试环境升级；升级前备份数据库 |
| 影响面 | 桌面客户端（Linux / Windows / macOS）+ 服务端镜像 + 管理后台登录配置 |

| 更新通道 | beta 预发布，不会进入正式客户端 `releases/latest` 更新通道 |

## 一、这一版包含什么

### 1. 企业微信 / 钉钉扫码登录

- 服务端新增企业微信、钉钉扫码登录流程（二维码启动、回调、轮询、用户建档）；
- 管理后台「认证配置」新增企业微信 / 钉钉扫码登录配置：AppKey、AppSecret、回调地址等；
- 客户端登录页支持企业微信 / 钉钉两种扫码方式；
- 登录页改为 WorkBuddy 式体验：
  - 品牌主视觉 + 一个主「登录」按钮；
  - 企业微信 / 钉钉图标切换，默认企业微信；
  - 点击登录后打开系统浏览器展示官方扫码页；
  - 客户端保持「登录中…」，扫码确认后自动进入主界面；
  - 浏览器没有自动打开时，可复制登录链接或重新发起登录；
  - 保留本地账号登录为二级入口，以及客户端内扫码兜底。

### 2. 账号卡显示真实姓名与来源

- 登录会话携带服务端下发的 `display_name` 和登录来源（`local` / `wecom` / `dingtalk`）；
- 左下角账号区显示员工真实姓名，不再显示 RBAC uid；
- 姓名前显示企业微信 / 钉钉品牌图标；本地账号仍使用首字母头像；
- 旧会话需要重新登录一次才会带出姓名和来源。

### 3. RBAC 外部身份源（默认关闭）

- 服务端支持在扫码回调后调用 RBAC 的 `/internal/v1/identity/resolve` 解析员工身份；
- 解析成功后以 RBAC uid 建档，支持同步部门到本地组；
- 404 / 409 / 停用 / 服务不可用等情况 fail-closed，并映射为可本地化的登录失败文案；
- 管理后台新增外部身份源配置：服务地址、访问令牌、适用的扫码方式、超时、部门同步开关；
- **默认关闭**，未配置 `identity.external` 的部署保持原有行为。

## 二、升级注意事项

1. **先升级服务端，再升级客户端**：扫码登录依赖服务端新的二维码/回调接口。
2. 企业微信 / 钉钉扫码需要在对应开放平台配置回调地址，并在管理后台填写应用凭据。
3. RBAC 外部身份源是可选配置；启用前请确认 RBAC 地址、令牌和返回契约，建议先在测试环境验证。
4. 旧客户端会话没有 `display_name` / 登录来源字段，升级后重新扫码登录一次即可正常显示。
5. beta 包用于验证，不建议直接替换生产正式渠道。

## 三、已知限制

- 浏览器是否自动打开取决于操作系统和默认浏览器；打不开时使用「复制登录链接」。
- 钉钉官方扫码页在已登录钉钉的浏览器中可能显示「立即登录」而不是二维码；两种方式都会完成授权。
- 企业微信 / 钉钉回调地址必须与开放平台登记一致，否则扫码后无法完成登录。
- RBAC 身份解析失败时登录会拒绝，不会回退成本地账号。

## 四、验证与回滚

- 已通过客户端登录页、扫码会话映射、RBAC 身份解析、WebAdmin 认证配置及全量门禁用例；
- 已用真实企业微信 / 钉钉账号完成浏览器扫码 → 客户端自动进入的端到端验证；
- 回滚：回退本版本部署即可；RBAC 外部身份源默认关闭，回滚不影响未启用的部署。
