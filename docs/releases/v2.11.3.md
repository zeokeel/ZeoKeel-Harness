## 一、本版修复：交互式 HTML 预览白屏

### 1. 问题

桌面端右侧 HTML 预览有两条路径：

- 开启「显示代码工作视图」：使用 Blob URL + `sandbox="allow-scripts"` iframe，执行 HTML 内联脚本；
- 关闭「显示代码工作视图」：使用 `srcDoc` 静态预览，不执行脚本。

应用窗口的 CSP 中 `frame-src` 原先只放行 `'self'` 和 `https:`，没有放行 `blob:`。因此在 macOS 客户端上，开启交互式预览时 Blob iframe 被拦截，右栏显示空白；关闭视图后静态预览正常。

### 2. 修复

- `frame-src` 增加 `blob:`，允许应用自行创建的 Blob iframe 通过 CSP；
- 同步更新 CSP 能力测试的批准能力表与正向锚点；
- 保留 `'self'` 与 `https:`，扫码登录等既有 iframe 能力不变；
- 未修改脚本源、worker 源、网络源或上游 `deepseek-harness` 子模块。

### 3. 安全边界

- Blob iframe 仍使用 `sandbox="allow-scripts"`；
- 未授予 `allow-same-origin`，不能访问父页面；
- 只增加应用自身创建 Blob URL 的 frame 能力，不放开任意网络 iframe。
